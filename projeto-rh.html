HR System: Plataforma Completa de Gestão de Pessoas

Aplicação completa desenvolvida com Power Platform para a gestão integrada e inteligente de todos os ciclos de vida do colaborador, desde o recrutamento até a administração de benefícios e avaliação de desempenho.

2024 • Concluído (Conceito para Portfólio)
Segmento: Tecnologia / Serviços
Duração: 4 Semanas

Demonstração do Sistema

Desafio do Cliente

Empresas em crescimento com um alto volume de contratações e uma gestão de benefícios complexa enfrentam:

  • Processo de Recrutamento Lento: Dificuldade em gerenciar o funil de candidatos, com informações dispersas e falta de rastreabilidade do processo seletivo.
  • Gestão de Benefícios Ineficiente: Administração manual de múltiplos benefícios, resultando em erros de cálculo e baixa taxa de adesão.
  • Falta de Visão Estratégica: Ausência de dashboards e relatórios em tempo real para monitorar indicadores-chave de RH.

Solução Implementada

Desenvolvimento de uma plataforma modular e visualmente moderna, utilizando o Power Platform para garantir escalabilidade e integração com o ecossistema Microsoft 365.

Módulo de Recrutamento e Seleção (Power Apps)

Interface dedicada para a criação e gestão de vagas, acompanhamento do funil de candidatos e comunicação centralizada com os gestores.

Gestão de Benefícios (Dataverse e Power Apps)

Catálogo digital de benefícios com informações detalhadas, valores e taxas de adesão. Permite ao RH gerenciar a ativação e desativação de benefícios por colaborador.

Dashboard de Performance (Power BI)

Painel executivo que consolida métricas de todos os módulos (Recrutamento, Benefícios, Colaboradores), fornecendo uma visão 360º para a tomada de decisão.

Passo a Passo da Implementação

Abaixo, detalhamos as etapas de desenvolvimento do HR System, desde a concepção até a entrega, incluindo a demonstração visual e os principais trechos de código Power Apps/Power Automate.

Etapa 1: Estrutura de Dados (Dataverse)

O coração do sistema é o Dataverse, onde as seguintes tabelas foram criadas para garantir a integridade e o relacionamento dos dados:

  • Tabela Colaboradores: Armazena dados pessoais, cargo e status.
  • Tabela Vagas: Gerencia o ciclo de vida das vagas e seus requisitos.
  • Tabela Beneficios: Catálogo de benefícios e regras de adesão.
  • Tabela Candidatos: Rastreia o funil de recrutamento.

Etapa 2: Lógica de Negócio (Power Automate)

Um dos fluxos mais críticos é a notificação de novas candidaturas e a aprovação de vagas. O trecho abaixo mostra a lógica de envio de notificação via Teams para o gestor responsável pela vaga:

// Exemplo de Ação no Power Automate: Enviar Notificação no Teams

Etapa 3: Interface de Usuário (Power Apps)

A tela de Gestão de Benefícios (vista no vídeo) utiliza uma galeria para exibir os cartões de benefícios. A fórmula Power Fx abaixo é usada para filtrar a galeria e exibir apenas os benefícios ativos:

// Fórmula Power Fx para a Galeria de Benefícios
Filter(
    'Tabela Beneficios',
    Status = 'Status Beneficio (Beneficios)'.Ativo
)

// Exemplo de fórmula para o botão "Ver Detalhes"
Navigate(
    ScreenDetalhesBeneficio,
    ScreenTransition.Fade,
    {
        BeneficioSelecionado: ThisItem
    }
)

Etapa 4: Visualização de Dados (Power BI)

O dashboard de performance utiliza o Dataverse como fonte de dados. A medida DAX abaixo calcula a Taxa de Turnover (exemplo de KPI estratégico):

// Medida DAX para Taxa de Turnover
TaxaTurnover = 
DIVIDE(
    COUNTROWS(FILTER('Tabela Colaboradores', 'Status' = "Desligado")),
    AVERAGEX(
        SUMMARIZE('Tabela Colaboradores', 'Data de Admissão', "Total", COUNTROWS('Tabela Colaboradores')),
        [Total]
    )
)
